# .github

Shared defaults for every repository in the [txsure](https://github.com/txsure)
organization.

| Path | Purpose |
|---|---|
| `profile/README.md` | The org landing page rendered on <https://github.com/txsure>. |
| `ISSUE_TEMPLATE/` | Default bug report and feature request forms, used by repositories that do not define their own. |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template. |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1, applies to all our spaces. |
| `SECURITY.md` | How to report a vulnerability privately. |
| `SUPPORT.md` | Which channel to use for what. |

Files here only take effect for a repository that does not ship its own copy, so anything
repo-specific belongs in that repository. Product code lives in
[txsure/txsure](https://github.com/txsure/txsure).
